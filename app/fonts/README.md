# Fonts Directory

This directory contains custom fonts for the PageJoy application:

1. NotoSansSC - For Chinese text
2. Lato - For English text

To use these fonts in the application, download the font files and place them in this directory:

- NotoSansSC-Regular.ttf
- NotoSansSC-Bold.ttf
- Lato-Regular.ttf
- Lato-Bold.ttf
